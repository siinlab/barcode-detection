# Barcode Detection and Recognition Training Dataset.

Due to the large size of the dataset, it is not included in the repository. However, it can be downloaded from the following links:
- [Barcode Detection Dataset](https://datasets.siin.ai/Barcode/latest/barcode-detection.zip)
- [Barcode Recognition Dataset](https://datasets.siin.ai/Barcode/latest/barcode-recognition.zip)

Alternatively, you can use the following command to download the datasets directly:

```bash
wget https://datasets.siin.ai/Barcode/latest/barcode-detection.zip
wget https://datasets.siin.ai/Barcode/latest/barcode-recognition.zip
```
To unzip the downloaded datasets, use the following command:

```bash
unzip barcode-detection.zip
unzip barcode-recognition.zip
```

Optionally, delete the zip files to save space:

```bash
rm barcode-detection.zip
rm barcode-recognition.zip
```
